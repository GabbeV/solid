# Constructed held resume and ordinary observer delivery

The earlier body theorem had a raw owned-state constructor at the body task, and
its full-World hold-before-resume equation remained unproved. This extension
avoids assuming that equation. A checked projection computes the source view of
the real hold/list operations from the initial source view. Separate control
observations retain action captures/methods, ambient question/depth/future and all
transaction open counts. Other transaction fields are not inferred from the
source projection.

Actual default signal/render/link construction, action allocation/opening and
source holding now construct the fresh-resume profile and its original one-action
debt. Actual resume, any finite admitted setter body and terminal return retire
that obligation; a checked corollary reads zero from the actual live group. Values
are arbitrary represented `R.Value`, not restricted to natural-number payloads.
The finite body grammar gives termination and its structural core-step bound.
The default-comparison/no-override scope is retained.

The ordinary delivery composition additionally allocates an actual pending input,
permits an arbitrary finite wait-helper prefix, registers a fresh yielded wait,
and derives the actual first-match lookup using the observer-arena freshness
invariant. Registration constructs the source/profile/capture/debt facts used by
the first-delivery theorem. No intermediate healthy profile, lookup answer,
resolver result or final count is supplied by the caller. The body restores any
saved caller stack, and after any finite admitted helper suffix a repeated current
lookup on that observer preserves the entire Machine. This is once-only handling
of this wait cell, not a global once-only action/flight ledger.

This is a raw constructor/controller composition. It does not establish the full
public generator invocation/parking prefix or host delivery through outer
from/deferred interception. Arbitrary helper histories have their existing private
operation domain; they are not a claim that every such history is a valid public
IO protocol. Source-cache redirects, distinct-component joins during preparation,
queued flush, global flight accounting and rendered publication remain open.
The generic captured-alias delivery results remain separate and unchanged; this
constructed family starts with its directly allocated canonical group.
