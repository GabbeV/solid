# Joined controllers with real setter bodies

The constructed family now performs the real signal/render/link construction,
first action create/open and source hold, second action create/open, and a join
in either direction. Either controller can then resume, execute any finite list
of real default updater setters, and terminate. The other method header remains
arbitrary and is not executed in this theorem. Fulfillment and caught rejection
select the same admitted terminating body grammar.

No intermediate World, source profile, cache, captured identity, resolver answer
or count is supplied to the closed constructor theorem. A generic contract uses
a `Ready` certificate for its initial first-controller boundary. The separate
`held-first-ready-construction` factory proves every field from the raw
construction, and the closed body root composes that factory with the generic
contract. These are constructive proof fields, not axioms or an assumed invariant
at every machine task. The generic contract also admits other source heaps that
satisfy this initial certificate; its concrete factory uses the fixed raw graph.

The join derives allocation, terminal representative and source heap facts. It
retains both original action captures and the source cache, even when these are
different identities. A proof-only virtual cache/selector view reconstructs the
body certificate for the new representative. It performs no runtime store. An
empty body retains the old cache; the first real setter resolves it before
comparison. Actual core execution is bounded structurally by two terminal steps
plus five steps for each setter expression. The resulting output-masked World
is the actual retirement target with one remaining obligation, and a separate
root restores the arbitrary caller value stack. Output Promise adoption and the
queued continuation are not confused with retiring the captured obligation.
