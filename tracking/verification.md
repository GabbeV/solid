# Verification and trust boundary

Pins: Solid `d2ad8b288886a5c7171e6746ccc019ad1d08d8ab`; Bend
`e5527d5be0c441d00f1f7d2fb61eb464fa478e5c` (2.0.37); Lean 4.34.0;
Bun 1.3.14. Dependency versions/integrities are in package-lock.json. Exact
vendored source hashes and production flags are in upstream/pins.json.

- `npm run build`: removes stale runtime output, checks Bend, emits one JS module,
  and bundles the pinned full Solid production entry with esbuild.
- `npm test`: deterministic shared scenarios, independently evaluated callbacks,
  exact compute/read/apply traces, outside reads, visible text and graph invariants.
  No wall-clock sleeps or expected traces generated by the Bend scheduler.
- `npm run test:alignment`: read-only upstream-impact report checks and a direct
  comparison with pinned TS markRefresh, including target/downstream flags and
  staged-read state. The probe exposes the actual helper beside the full index.
- `npm run mutations`: compiles four incorrect runtime copies and requires
  differential assertions to reject each. The active source is not mutated.
- `npm run check`: validates temporary-deviation records and their reviewed pin,
  seals active deviation IDs with the evidence, rejects upstream drift/stale builds, runs
  PROOF.bend with --verdict, checks no source changed during the run, and seals
  source/output hashes after success. Failed runs do not replace a sealed record.

Arbitrary-payload composed proofs passed the frontend but exhausted memory or
became impractical in the independent kernel. Canonical transition witnesses
reduced peak memory but still expanded too much when composing open-context
computations. They are not counted or retained as completed evidence.

The active roots instead directly check two closed composed regressions through
the actual API/driver and a general execution-path lemma for arbitrary states.
They succeed with the independent kernel. General operation-level refinements,
arbitrary payloads, graph families and histories remain explicit work.

Trusted: the pinned Bend parser/elaborator and independent kernel, their build,
backend code generation, Node/Bun execution, the small JS adapter and numeric range
contract. Source correspondence is reviewed and differentially tested; it is not a
machine-checked semantics proof of JavaScript. No wrapper/browser/compiler
verification project is claimed.

Source archives include upstream licenses. No upstream repository or remote branch
is modified or published by this project. Preserve the final archive and checksum
outside the execution workspace for protection against workspace loss.
