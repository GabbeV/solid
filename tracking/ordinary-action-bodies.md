# Finite ordinary setters inside real action bodies

This extension moves beyond queueing an arbitrary method or evaluating a single
literal return. It connects actual setter expression evaluation, source staging
and notification, a preserved input profile, arbitrary finite sequences of
setters and the real action-return path. Runtime, host, source pin and checker
profile are unchanged. It is not a full action/flight/publication theorem.

## Admitted language and observation

The body language is a finite list of `setter(() => value)` expressions followed
by a generator protocol return. Every assigned and returned value ranges over
all represented `R.Value`, and the list has arbitrary finite length. The updater
wrapper makes a returned callable data rather than another updater invocation.
Callback binding leaves this closed language unchanged for arbitrary argument
pairs/vectors. Next and caught-throw methods may enter the same body.

The ordinary profile names a valid signal node, default comparison, no held or
lane-override flag, imperative context0, a healthy fault field and an inactive
recursive heap-marking phase. It contains a finite certificate of actual
subscriber `nextSub` lookups and sufficient source arena budget for that path.
It is an initial-state certificate, not an assumed successful transition or final
count. General graph reachability/forest-size bounds remain separate. The raw
construction below supplies a real allocated signal/render node/link; generic
Bend operation contracts are not a machine-checked TypeScript equivalence claim.

The outer observation masks only nodes, heap buckets/minimum/maximum, pending
queue bookkeeping and four scheduling fields. It retains fault, actor cells,
wait cells, transaction storage, question/context, comparators and all other
World fields. A separate committed-storage observation retains every cached node
value, rendered tree and application trace. Thus an ordinary write can genuinely
stage data and enqueue work while these observations stay protected.

## Checked dependencies and construction

- Actual heap insertion retains the full outer observation outside recursive
  marking. Finite subscriber-path induction carries it through the real walk.
  The actual `insertSubs` prefix preserves head/membership/budget and uses its
  arena-derived budget; successful traversal does not come from a final premise.
- `ordinary-stage-health`, `ordinary-setter-health` and the topology contracts
  retain health, source shape and control storage through actual intake, default
  comparison, staging, notification and scheduling. Suppressed equal writes are
  included. Promotion/computed-time/held branches are not removed from runtime;
  the input profile selects the ordinary source branch.
- `ordinary-write-profile` constructs the next certificate after each actual
  write. It derives health, kind/configuration, current identity/head, comparators,
  path and room from the retained observations. Path transport constructs the next
  certificate from unchanged link storage. No later profile is assumed.
- `ordinary-write-history` constructs this invariant for any finite setter list.
  A fresh signal/render/link construction establishes a nonempty initial family.
- `ordinary-body-evaluation` follows the actual `Core.step` relation. One body
  evaluates in `1 + 5*n` steps; its `ActionStepReturn` takes one more. The bound
  follows syntax, and caller tasks and stack remain explicit. The theorem does
  not execute a caller's queued continuation or turn driver exhaustion into
  successful completion.
- `ordinary-body-retirement` transports the original captured-group route and
  positive count through the writes and depth exit, then invokes actual done.
  It handles arbitrary certified representatives and arbitrary remaining debt.
  The constructed controller uses actual action creation/opening/captured resume;
  the direct corollary gives zero live group debt without a final-count premise.

`ordinary-body-construction-normal` is a proof normal form of this raw constructor
family. Its full World equation is checked against actual create/open/resume.
`ordinary-profile-transport` derives the profile across proved source-storage and
control equalities. Neither is an alternate runtime or scheduler. Allocated
identities are obtained from the real constructors; actor0, signal1, group1 and
result1 belong to distinct arenas, rather than being interchangeable aliases.

## Completion and remaining scope

The final result may be adopted as a Promise after the group obligation has been
retired. Zero group debt therefore does not imply a settled action output.
Observer delivery, `ActionSliceEnd`, its flush and rendered publication remain
queued at the theorem's endpoint. The separate public native controls run those
later stages for a synchronous memo/render graph; finite controls do not prove
arbitrary eventual reveal or global flight accounting.

The constructed entry is a raw constructor/controller integration. Complete
public invocation-to-host delivery reachability, arbitrary user code, throwing
bodies, held/override/custom-comparator setters, recursive-marking reentrancy,
supersession/disposal and nonempty rendered-flight publication remain open.
Already-held writes need a separate same-component join/extension argument and
must not be treated as covered by this ordinary profile. Earlier literal-body,
arbitrary pre-evaluation method and helper-prefix/suffix domains remain intact.
