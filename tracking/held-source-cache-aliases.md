# Real setter bodies with redirected source caches

Captured action identity and a source node's cached group are different fields.
The earlier generic delivery theorem admitted redirected action captures while
requiring a canonical source cache. After a real hold followed by a group merge,
the source cache can still name the old group. The runtime resolves and stores
that cache before comparison; equality suppressing the write must not skip it.

`held-source-cache-rebase` proves the real `txOf` result from an initial finite
redirect certificate, cache-origin equality and structural arena room. It executes
the actual resolver and extension store. Given the ordinary held profile with its
initial cache field observed at the representative, the actual first setter
constructs the canonical successor profile. This initial field observation changes
only the cache in proof data; it is not a runtime workaround or an assumed
successful `txOf` result. Other metadata/count/route fields remain real.

`held-source-cache-body` derives the actual pre-updater health, signal, override
and comparator facts, runs the first five core steps of a real setter body and
constructs its successor certificate. The previous held-body induction then
handles any finite tail. Both the complete Machine result and final held profile
are checked for a nonempty body, arbitrary represented values and caller work/
stack. The cost follows syntax. A zero-setter body deliberately does not resolve
the source cache; no equality to a canonicalized World is claimed for it.

Four roots extend718 to722. The isolated cache/history book passes in7.93s and
the actual nonempty body/profile book in7.85s under the unchanged compact limits.
The finite controls retain all2832 earlier bodies and add144 cases that hold the
source before merging through chains of lengths1,3,8. They cover fresh/current
entry, fulfillment/rejection, an equality-suppressed first setter, long tails and
zero setters retaining the old cache. Total2976 bodies,31500 actual setter
expressions,2080 held bodies,32 native generator/port controls and16 pending output
adoptions. These controls do not assume the old full-World hold/resume commutation
for source-cache aliases; that equality is not the same state construction.

The new theorem starts at the body task. Lifting both source-cache and captured
alias certificates through actual resume, distinct-component preparation joins,
full public protocol reachability, queued publication and a global action/flight
ledger remain open. No source/runtime algorithm or checker rule was changed.
