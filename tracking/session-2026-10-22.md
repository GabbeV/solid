## Three newly confirmed upstream defects

All reproduce in unchanged Solid, have passing controls, saved/reopened JSX
shares, isolated candidate patches, candidate builds/full suites and size checks.
The native baseline repros also still reproduce on cdd95616. No issue or PR has
been filed for them. Patch applicability to cdd95616 is checked; candidate suite
and size measurements retain their explicitly recorded aece1d44 base.

1. [Buffered from + deferred refetch](https://s.olid.uk/id/VfGd9n1GQDKvvXQNGb2MWw):
   createDeferred's stream wrapper calls p.then on the first next result, but
   from can legally return a buffered IteratorResult directly. A refetch throws
   `p.then is not a function`; createMemo handles the same stream. Candidate:
   use the existing isThenable test for this first result. See
   [record and validation](upstream/deferred-buffered-from.md).
2. [Synchronous unsubscribe failure](https://s.olid.uk/id/7C4FKqDuRECgu4aY9Qi-4g):
   a subscription that completes synchronously returns an unsubscribe function
   after close has run. That late cleanup is called without close's catch, so
   its exception escapes, can replace a source error and can prevent rendering
   a successfully buffered value. Deferred completion is a passing control.
   Candidate: match close's existing exception containment at this branch. See
   [record and validation](upstream/from-sync-unsubscribe.md).
3. [Deferred error waits for an obsolete request](https://s.olid.uk/id/l7LoIOhpS_mHSJwY8p2j8w):
   an ordinary synchronous error after a refetch leaves that old flight/mark
   installed. until or refresh waits for the obsolete request before rejecting
   with the already-current error. Without a prior request it rejects promptly.
   Candidate: land the superseded flight on this ordinary-error catch branch,
   keeping the NotReady parking branch and original throw. See
   [record and validation](upstream/deferred-superseded-error.md).

No candidate is installed in the translation. The third defect is deliberately
preserved by four public baseline cases. The first two touch explicitly unported
from/stream-wrapper paths. The active semantic deviation register is empty.
